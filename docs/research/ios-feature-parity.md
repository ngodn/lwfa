# Native iPad feature parity inventory

Code audit, 2026-09-12. Restyle continuation findings: [review and validation](ios-restyle-continuation.md). Browser baseline: repository `5e638fc`, including the 1.5.10 shell. Native snapshot: the current `clients/ios` working tree after the native panels, canonical layout bridge, input, and media implementations. This is a source inventory, not a claim that device behavior has been tested. Update individual rows as implementation and device validation land.

**Implemented** means a corresponding native code path exists. **Partial** means some behavior exists but listed capabilities are absent. **Missing** means no corresponding native implementation was found. A protocol enum case without a consumer or a visible control does not count as a finished feature.

Browser paths below are relative to [`packages/shell/src`](../../packages/shell/src). Protocol names refer to [`packages/proto/src/index.ts`](../../packages/proto/src/index.ts), mirrored by [`crates/lwfa-proto/src/lib.rs`](../../crates/lwfa-proto/src/lib.rs). Native filenames refer to [`clients/ios/NativeApp`](../../clients/ios/NativeApp). Shared portable state, packet parsers, and protocol helpers live in [`LWFACore`](../../clients/ios/Sources/LWFACore). `LayoutBridge.ts` bundles the canonical browser strip policy into JavaScriptCore, without a WebView. UIKit and SwiftUI render the app and handle input.

## Protocol and acceptance work

The native decoder preserves typed core events and known administration payloads. Session event consumers now route apps, accounts, gaming, clipboard, chooser, upload, touch and layout actions to the panels listed above. Extensible JSON envelopes are transport helpers, not a substitute for the native controls.

Every feature row now has a native implementation path in this source snapshot. Browser Fullscreen API, React reload recovery, and AudioWorklet telemetry use their native UIKit/OS/AVAudioEngine equivalents. This is source coverage, not a declaration of full verified parity: the device and end-to-end checks below remain open. A successful compile does not establish device behavior parity.

The complete portable Swift suite passed 50 tests in this session. It covers protocol fixtures, full-width IDs, media bounds and malformed packets, source-owned input, canvas geometry, browser controller backup fixtures, transfer envelopes, Opus and bounded decode admission. The canonical layout bridge has its own policy comparison tests. These tests do not substitute for a connected iPad exercising UIKit gestures, VideoToolbox, Metal and AVAudioEngine.

- [ ] Every inventory row has native source references, an explicit completed/remaining status, and behavior tests where state transitions matter.
- [ ] Canonical Rust protocol fixtures validate all supported request/response shapes, including null versus absent, permission allowlists, error envelopes, and UInt64 identifiers.
- [ ] Window/workspace geometry matches browser policy, preserves inactive windows, respects follower roles, and passes the existing edge-strip/normalized-input/Wine sizing regression scenarios.
- [ ] Connect, reconnect, take-control, permission changes, modal interactions, backgrounding, and device disconnects cannot leave input held or route it to an unintended window.
- [ ] Clipboard/chooser/upload tests cover expired tickets, cancellation, resumed offsets, checksum failures, permission changes, and progress without starving media/input.
- [ ] Native iPad testing confirms hardware-controller holds/rapid presses/triggers/sticks, multitouch, physical keyboard, pointer and virtual overlays.
- [ ] Native iPad testing confirms HEVC/H.264/JPEG changes, multiple live windows, PCM/Opus, mute/volume/quality, audio route interruptions, and bounded latency after network stalls.
- [ ] No WKWebView shell replacement, hidden unimplemented panel, disabled placeholder button, or raw JSON editor is counted as feature parity.
- [ ] Linux ARM64 iOS build/sign/install verification is recorded separately from feature parity and physical-device validation.
