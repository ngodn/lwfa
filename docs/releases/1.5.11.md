This release includes lwfa 1.5.11 for Linux and the native iPad client 0.2.12 (12).

### Added

- Add a native iPad app with SwiftUI panels, Metal video rendering, audio, physical and on-screen controllers, and saved sessions.
- Provide Linux scripts to build, sign and install the iPad app.

### Changed

- Balance grouped windows using the available space. Six and eight windows form equal rows where the canvas proportions allow, with corresponding layouts in portrait.
- Use distinct icons for Immersive mode and window fullscreen, with clearer action labels.

### Fixed

- Prevent odd window groups from giving some windows roughly twice the area of others.
- Keep sibling groups consistent when canvas dimensions differ by one pixel.
- Give iPad controller pads and toolbar actions direct native touch targets. Keep Edit, Show/Hide, Guard, Settings and Close above the pads and visible at low pad opacity.
- Block stray touches across the full canvas when the controller guard is enabled.
- Animate iPad window movement in Arrange mode and keep video, input and borders together while moving.

### Upgrading

- Upgrade the Linux installer and refresh the browser to load the updated layout.
- The IPA supports iPadOS 26 and later and requires signing with your Apple account. With the iPad connected and unlocked, run `bash scripts/install-ios.sh releases/lwfa-ipad-0.2.12.ipa` after downloading it into `releases/`.
- The IPA build and automated checks passed. The latest controller-toolbar and window-animation behavior still needs physical-device verification.
