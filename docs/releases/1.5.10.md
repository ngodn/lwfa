This release includes the gaming features prepared for 1.5.9 and the controller UI fixes in 1.5.10. Version 1.5.9 was not published separately.

### Added

- Add Proton, LSFG, and Framegen tabs to the Gamepad settings panel, with component installation and per-game profiles.
- Install GE-Proton11-6 and the lwfa Canvas patch together from the Proton tab. Host launches use the original GE runtime; lwfa launches use the patched runtime.
- Add managed LSFG with per-game frame multipliers and motion detail settings. Requires a purchased copy of Lossless Scaling installed through Steam.
- Add experimental OptiScaler frame generation for compatible games, with private per-game files and checks for conflicting graphics injectors.
- Show GPU capture and CPU copy activity in engine diagnostics.

### Changed

- Open controller and gaming settings from the navigation Gamepad button. Use the Controller tab's "Show the gamepad" switch to show or hide on-screen controls.
- Keep gaming profiles and downloaded components across lwfa upgrades.

### Fixed

- Make the gamepad visibility switch control the displayed on-screen controller and stay synchronized with its toolbar.
- Keep the settings panel open when launched from the controller toolbar.
- Leave layout editing when hiding or switching away from the gamepad.

### Upgrading

- Refresh the browser after upgrading to load the updated navigation.
- After installing managed Proton, restart Steam when your games are closed and select the lwfa Canvas tool in the game's Compatibility settings.
- To use LSFG or Framegen, copy the launch option shown in its tab into the game's Steam launch options. Use one frame-generation provider at a time. Gaming management requires Python 3.11 or newer; Framegen also requires Bubblewrap with overlay support and a 7-Zip extractor.
