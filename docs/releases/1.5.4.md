### Added

- Add an owner-only Restart lwfa button below sign-out in Session, with a confirmation dialog and automatic reconnect.

### Changed

- Initialize Xwayland's desktop from the first controlling browser's size instead of the host monitor. Keep it stable while apps are running.
- Soften focused window outlines with a thinner, less opaque orange border and lighter shadow.

### Removed

- Temporarily disable Sharper and More space. Windows use 1x while display scaling compatibility is reworked.

### Fixed

- Preserve window widths and workspace arrangements when refreshing the browser.
- Preserve fullscreen game dimensions and fit the complete image into its browser window, including pointer coordinates in letterboxed views.
- Keep dialog keyboard navigation out of games and release held keys when a dialog takes focus.

An intermittent Wine mode-emulation stall remains under investigation. This release does not claim to resolve every game-specific freeze or cursor offset.

### Upgrading

- Reload open browser tabs after upgrading to load the updated shell.
- Without an explicit `session.xwayland_resolution`, automatic Xwayland startup and the initial terminal wait for the first controlling browser. The shared X11 monitor stays fixed until lwfa restarts; rotating the browser does not change a running game's resolution.
