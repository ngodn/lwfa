**Safari/WebKit physical-controller issue:** physical buttons can miss presses
or remain held in the reported iPad setup, especially LB/RB. Chrome worked in
the user's follow-up test, and on-screen controls work in Safari. Use Chrome or
on-screen controls if affected. This release does not claim to fix Safari's
physical-controller behavior.

### Added

- Play with a physical controller, including analog sticks and triggers.
- Hide on-screen controls independently using the button between Edit and the
  shield. The controller and shield stay enabled.
- Reset physical controller state and export troubleshooting traces from
  Gamepad settings.
- Pan game cameras by moving the mouse to fullscreen window edges.

### Changed

- Widen gamepad toolbar buttons for easier touch access.
- Improve automatic stream adaptation and recovery as connection conditions
  change, including JPEG fallback pacing.

### Fixed

- Release held controller input when the browser loses focus and release held
  touch controls when hiding the layout or entering Edit.
- Preserve focus when closing panels and dialogs; prevent passive follower
  sessions from taking focus and improve Xwayland focus repair.
- Correct black strips along window edges and stale frames after stream changes.
- Improve audio playback recovery and cleanup across reconnects and suspension.
