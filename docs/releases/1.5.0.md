### Added

- Choose per-window scaling from 0.5x to 2x in the Windows panel. Sharper adds
  detail at the same interface size for native Wayland apps; More space fits a
  larger workspace into the same browser tile, including Xwayland apps.
- Let Sharper follow the controlling display's density with Auto, up to 2x.

### Changed

- Update the audio codecs, frontend toolchain, and compatible Rust dependencies.
- Limit cached CPU frame memory when resizing large or dense windows.

### Fixed

- Keep pointer and touch input aligned with scaled windows and apps that limit
  their requested size.
- Let Xwayland pointer movement reach the full enlarged workspace.
- Keep the local preview and popups aligned with the app's actual dimensions.
- Release closed-window encoders promptly, even when no further frames arrive.
- Free browser frames and decoders for windows that close while disconnected.
- Read the video stream's actual profile and size, and fall back when the
  browser cannot decode it.

### Upgrading

Upgrade the engine and reload every connected browser together. This version
uses an updated shell protocol.

Safari/WebKit physical-controller input remains a known issue in the reported
iPad setup. The user's Chrome test and Safari on-screen controls worked.
