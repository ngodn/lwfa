### Changed

- Restore browser-driven Xwayland monitor sizing. Fullscreen and ordinary windows receive their canvas dimensions, including after resizing or rotation.
- Fill Xwayland canvases without the blanket aspect-fit margins introduced in 1.5.4. Games can still draw their own letterboxing or retain a deliberately selected resolution.

### Removed

- Remove Sharper and More space, including their settings, protocol commands and engine state. The obsolete `session.xwayland_resolution` setting is ignored.

### Fixed

- Preserve the existing right and bottom capture-edge corrections on both GPU capture and CPU readback.
- Add a separate GE-Proton 11-6 compatibility tool for Wine's stale display modes, DPI arithmetic, fullscreen presentation, hit testing and cursor bounds during browser resizing.
- Keep host launches on original GE libraries. Refuse to attach to an active prefix using the other runtime, without stopping its applications.

### Upgrading

- Reload browser tabs after upgrading. The shell and engine use protocol version 2.
- The test installer includes the compatibility components. Registration requires the matching original `GE-Proton11-6-x86_64` installation.
- Restart Steam after installation and select **lwfa GE-Proton 11-6 (Canvas)** in the game's **Properties > Compatibility**. Existing game selections are unchanged.
- Close applications using the game's prefix before switching between host and lwfa sessions. Existing system Wine and GE installations are preserved.

The compatibility components in this test package are built for this host.
A portable release requires a separate Steam Runtime SDK build. Tests cover
32-bit and 64-bit GDI/DXVK fixtures, rendering edges, DPI transitions, cursor
input and launcher isolation. Real-game testing is still required before release.
